# better-ui

This 'skill' documents UI improvements applied from the better-ui guidance:

- Micro-interactions: consistent `--transition-base` and `--transition-fast` timings.
- Hover elevation: `--shadow-sm` and `--shadow-lg` CSS variables used for card lift.
- Button and interactive controls have clear hover and focus states.
- Respect `prefers-reduced-motion`.

Files updated: `styles.css`, `script.js`.
