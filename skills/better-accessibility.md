# better-accessibility

Accessibility changes applied:

- Added a visible `Skip to content` link for keyboard users.
- Nav has `role="navigation"` and ARIA label.
- Theme toggle includes `aria-pressed` and updates for state.
- Focus-visible outlines and focus styles added for keyboard users.
- Lightbox focuses the close button on open and supports `Escape` to close.
- Increased focus contrast and explicit focus indicators.

Files updated: `index.html`, `styles.css`, `script.js`.
