# Graphic Design Portfolio (sample)

Open `index.html` in a browser to view the portfolio.

This sample demonstrates:
- Dark theme with provided CSS variables
- Masonry gallery using `column-count` (3/2/1 responsive)
- Card hover overlay and lift
- Fullscreen lightbox with uncropped images (`object-fit: contain`)

Files:
- [index.html](index.html)
- [styles.css](styles.css)
- [script.js](script.js)
- assets: sample SVGs demonstrating mixed aspect ratios

Branding: Aliciagiks4art

Improvements applied inspired by open-source skill sets:
- better-ui: micro-interactions and hover elevation (see `skills/better-ui.md`).
- better-accessibility: skip link, focus-visible, ARIA improvements (see `skills/better-accessibility.md`).
- better-typography: font/line-height changes (see `skills/better-typography.md`).
- better-colors: theme toggle and color variables (see `skills/better-colors.md`).
